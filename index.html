01 /PROFILE

大阪を拠点に活動するVJ。全国のナイトクラブや大型音楽フェスを手がける総合エンターテインメント企業で、インハウスデザイナーとして働いています。現場で培ったオペレーションの感覚と、デザイナーとしての視点。その両方から、音と空間に寄り添う映像を組み立てます。

02 /SERVICE

  • S-01 — VJ / VISUAL OPERATION

    VJ・映像オペレーション

    クラブやフェスの現場で、音に合わせて映像をリアルタイムに操作。機材の持ち込みから当日の進行まで対応します。

  • S-02 — LIVE VISUAL PRODUCTION

    LIVE VISUAL制作

    アーティストやイベントのコンセプトに合わせて、ライブ用の映像素材を制作。空間全体のトーンから設計します。

  • S-03 — LED INSTALL / RENTAL / SALES

    LEDの施工・レンタル・販売

    LEDビジョンの設営・施工から、レンタル・販売まで。会場の規模に合わせた構成をご提案します。
